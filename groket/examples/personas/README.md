# Persona examples

JSON personas for `~/.groket/personas/`.

| File | Purpose |
|------|---------|
| [`superpowers.json`](superpowers.json) | Enables marketplace **superpowers** for batch tasks that set `persona_id: superpowers` |

```bash
mkdir -p ~/.groket/personas
cp examples/personas/superpowers.json ~/.groket/personas/
```

Validated by `make examples-check`.
